What Is Python?

Discover Python, a beginner-friendly programming language used in automation, web development and AI.

What is Python?

Python is a programming language known for its readable syntax. Developers use it to build applications, analyse data and create AI systems.

Example

print("Hello, World!")

Output

Hello, World!

Remember

The print() function displays information on the screen.

PYTHON BASICS

Understanding Variables

Learn how variables store information that your Python program can use.

What is a variable?

A variable is a name that refers to a value. You can use it to store text, numbers and other data.

Example

name = "Python"
age = 30

print(name)
print(age)

Output

Python
30

Remember

Use meaningful variable names such as name, age or total_price.

What Is Artificial Intelligence?

Understand how AI systems perform tasks such as recognising patterns and generating text.

What is AI?

Artificial Intelligence is a field of computing focused on building systems that perform tasks commonly associated with human intelligence.

Everyday examples

  • Voice assistants
  • Recommendation systems
  • Image recognition
  • AI writing assistants

Remember

AI is a broad field. Different AI systems use different techniques and have different abilities.

MACHINE LEARNING

What Is Machine Learning?

Learn how computers use data to find patterns and make predictions.

How does it work?

Machine learning is a branch of AI in which algorithms learn patterns from data. A trained model can use those patterns to make predictions.

Example

A model trained on labelled email examples may learn to classify new emails as spam or not spam.

Basic workflow

  • Collect useful data.
  • Prepare the data.
  • Train a model.
  • Evaluate its performance.
  • Use it to make predictions.

CODING TIPS

How to Learn Coding Effectively

Build a consistent coding habit through small exercises and practical projects.

Try this approach

  • Learn one concept at a time.
  • Type and run the example yourself.
  • Change the code and observe the result.
  • Practise with small challenges.
  • Build projects as your skills grow.

Example challenge

Write a Python program that adds two numbers and prints the result. 

first = 10
second = 20

print(first + second)

Output

30
